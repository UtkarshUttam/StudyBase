Foundation of Percentages

CORE
📐
What is a Percentage?
DEFINITION ▶
Core Definition
Percentage = Per + Cent = "Per hundred"
x% means x out of every 100 · x% = x/100 = 0.0x
As Fraction

x% = x/100
So 35% = 35/100 = 7/20
Always simplify the fraction

As Decimal

x% = x ÷ 100
So 35% = 0.35
Move decimal 2 places LEFT

As Ratio

x% = x : 100
So 25% = 25:100 = 1:4
Part to whole relationship

Base Value

"% of WHAT?" always matters.
Base = the whole/original value.
Always identify base first!

Universal Formula
Percentage = (Part / Whole) × 100
Part = (Percentage × Whole) / 100 · Whole = (Part × 100) / Percentage
⚠️ Base Value Trap
60% of 50 ≠ 50% of 60? Actually they ARE equal! (both = 30) because a% of b = b% of a always. Use this to speed up calculations!
🧠 Core Rule
"Percent = Part per Hundred"
Whenever confused, convert to fraction /100 first. This eliminates 80% of percentage errors.
🔗
Ratio–Percent Relationship
BRIDGE ▶
If ratio a:b, then percentage of a
% of a = a/(a+b) × 100
If ratio is a:b:c → % of a = a/(a+b+c) × 100
⚡ Ratio to % Shortcut
Ratio 3:2 → Total parts = 5. First = 3/5×100 = 60%, Second = 2/5×100 = 40%
Ratio 1:3:1 → 20%, 60%, 20%
⚠️ CDS Trap
"A's salary is 25% more than B" vs "B's salary is 25% less than A" — These are DIFFERENT! First: A = 1.25B. Second: B = 0.75A → A = B/0.75 = 1.333B. 25% more ≠ 25% less from other side.

Percentage Increase & Decrease

HIGH YIELD
📈
Core Formulas — Increase & Decrease
FORMULAS ▶
% Increase
% Increase = [(New - Old) / Old] × 100
New value is MORE than original
% Decrease
% Decrease = [(Old - New) / Old] × 100
New value is LESS than original
Multiplier Method (Fastest!)
r% increase → Multiply by (1 + r/100) = (100+r)/100 r% decrease → Multiply by (1 - r/100) = (100-r)/100
20% increase → multiply by 1.2 · 15% decrease → multiply by 0.85
⚡ Multiplier Table — CDS Speed
5% increase → ×1.05 | 10% → ×1.1 | 15% → ×1.15 | 20% → ×1.2 | 25% → ×1.25
5% decrease → ×0.95 | 10% → ×0.9 | 15% → ×0.85 | 20% → ×0.8 | 25% → ×0.75
50% increase → ×1.5 | 100% increase → ×2 | 200% increase → ×3
⚠️ Classic CDS Trap: Increase then Decrease
If price increases by 20% then decreases by 20%, net change is NOT zero!
Net = 1.2 × 0.8 = 0.96 → 4% decrease. General formula: Net = (1+a/100)(1-b/100) - 1
↔️
Reverse Percentage (Finding Original)
REVERSE ▶
Reverse Formula — Find Original
If after r% increase, new value = N → Original = N × 100/(100+r) If after r% decrease, new value = N → Original = N × 100/(100-r)
Example: After 20% increase, price = 240 → Original = 240 × 100/120 = 200
⚡ Reverse % Quick Method
After 25% increase, value = 500. Original?
500 / 1.25 = 400 (Divide by multiplier)
After 20% decrease, value = 400. Original?
400 / 0.8 = 500
⚠️ % of What? Always Identify Base!
"Salary increased by ₹600, which is 20% increase" → Original = 600/20 × 100 = ₹3000, NOT ₹600+₹120
🏘️
Population Growth & Decay
APPLIED ▶
Population After n Years (r% growth)
P(n) = P₀ × (1 + r/100)ⁿ
P₀ = initial population · r = growth rate · n = years
Population Decrease/Decay
P(n) = P₀ × (1 - r/100)ⁿ
Used for depreciation, radioactive decay, disease spread
⚡ 2-Year Compound Formula
Net % change for 2 years at r% = 2r + r²/100
Example: 10% for 2 years = 20 + 1 = 21% net increase

Successive Percentage Changes

CRITICAL
⚡
Net Percentage Change Formula
MASTER FORMULA ▶
Two Successive Changes: a% then b%
Net % = a + b + (a×b)/100
+ve = increase, -ve = decrease · Works for any combination
⚡ Examples — Commit to Memory
+20% then +20% = 20+20+4 = +44%
+20% then -20% = 20-20-4 = -4%
+10% then -10% = 10-10-1 = -1%
-10% then -10% = -10-10+1 = -19%
+25% then -20% = 25-20-5 = 0% (back to original!)
⚠️ Sign Rule for Successive %
In formula a + b + ab/100:
If both increase → a×b/100 is positive (adds)
If one increase, one decrease → a×b/100 is negative (subtracts)
If both decrease → a×b/100 is positive (but a,b are both negative, so still net decrease)
Three Successive Changes: a%, b%, c%
Use multiplier: (1+a/100)(1+b/100)(1+c/100) - 1
Fastest method for 3+ changes — multiply then subtract 1
🧠 Memory Hook for Successive %
"Add, Add, then Add the Product÷100"
a + b + ab/100. The ab/100 term is always subtracted if signs differ. Remember: same signs → add the product, different signs → subtract.
🔄
Equivalent Single Percentage
EQUIVALENT ▶
⚡ Key Equivalents — CDS Favorites
Two equal increases of r% → Net = 2r + r²/100
r% up then r% down → Net = -r²/100 (always a loss!)
r% up then same as making original = r/(100+r) × 100% decrease needed
To cancel x% increase → need x/(100+x) × 100% decrease
To Restore After x% Increase
Required decrease % = x/(100+x) × 100
After 25% increase → need 25/125 × 100 = 20% decrease to restore
To Restore After x% Decrease
Required increase % = x/(100-x) × 100
After 20% decrease → need 20/80 × 100 = 25% increase to restore
⚠️ Most Repeated CDS Question Type
"If length increases 20%, width decreases 20%, area changes by?" → Area = L×W, Net change = -4% (use successive formula). Area decreases by 4%!

Profit, Loss & Discount — % Connection

SCORING
💰
Core Profit & Loss Formulas
FORMULAS ▶
Cost Price (CP)
→ Profit/Loss →
Selling Price (SP)
← Discount ←
Marked Price (MP)
Profit %
Profit% = (SP - CP)/CP × 100
Base = CP always for profit/loss %
Loss %
Loss% = (CP - SP)/CP × 100
Base = CP always for profit/loss %
SP from Profit%
SP = CP × (100 + P%)/100
20% profit → SP = CP × 1.2
SP from Loss%
SP = CP × (100 - L%)/100
15% loss → SP = CP × 0.85
Discount Formula
Discount% = (MP - SP)/MP × 100 SP = MP × (100 - D%)/100
Base = MP always for discount% · Discount is ALWAYS on Marked Price
⚠️ Critical: Profit% vs Discount% Bases!
Profit% base = CP | Discount% base = MP
These are DIFFERENT bases. Mixing them up is the #1 P&L error in CDS!
🏷️
Successive Discounts
DISCOUNT CHAIN ▶
Two Successive Discounts a% and b%
Net Discount = a + b - ab/100
20% + 10% successive = 20+10-2 = 28% (NOT 30%!)
⚡ Successive Discount Shortcuts
20% + 20% = 36% net | 10% + 10% = 19% net
25% + 20% = 40% net | 30% + 30% = 51% net
Always less than arithmetic sum!
SP = MP × (1-a/100) × (1-b/100)
Equivalent Single Discount for a% and b%
= a + b - ab/100 (same as successive % formula!)
Successive discounts use same formula as successive % changes
🔗
MP–CP Relationship (Profit After Discount)
COMBINED ▶
Finding MP when CP and Profit% and Discount% known
MP = CP × (100 + Profit%) / (100 - Discount%)
Example: CP=100, profit=20%, discount=10% → MP = 100×120/90 = 133.33
⚡ Break-Even Trap — CDS Favorite
Marked 40% above CP, discount 20% → Profit = ?
SP = 1.4 × 0.8 = 1.12 × CP → 12% profit
General: (1 + m/100)(1 - d/100) - 1 = net profit%

Percentage Applications

DIVERSE
📝
Exam Marks & Scores
CDS STAPLE ▶
Score → Percentage
% = (Marks obtained / Total marks) × 100
⚡ Exam Marks Tricks
Pass marks = P% of total → Min marks = T × P/100
"x% more than pass" → Obtained = Pass + x% of Pass = Pass × (1 + x/100)
"Failed by y marks" → Obtained = Pass - y
"Needed y more to pass" → same as above
⚠️ Common Exam Marks Trap
"Student A scored 40% and B scored 30% more than A" → B's score = A's + 30% of A's = 1.3A, NOT A + 30%of total
💵
Income, Expenditure & Savings
HIGH FREQ ▶
Key Relationship
Savings = Income - Expenditure If Income increases x%, Expenditure increases y% → Savings change = ?
Calculate new income, new expenditure, then find new savings, then % change
⚡ Income-Expenditure Shortcut
Income = 100, Expenditure = 80, Savings = 20
Income +20%, Expenditure +25% → New: 120, 100, Savings = 20 (no change!)
Rule: % change in savings = (ΔIncome - ΔExpenditure) / Original Savings × 100
🧪
Mixture & Alligation with %
ANALYTICAL ▶
Mixture of two % concentrations
New% = (Q1×C1 + Q2×C2) / (Q1 + Q2)
Q1,Q2 = quantities; C1,C2 = concentrations as percentages
⚡ Alligation for % Ratio
Mix solutions of 30% and 50% to get 40%:
Ratio = (50-40):(40-30) = 10:10 = 1:1
Higher%−Mean : Mean−Lower% gives mixing ratio

EXAM CRITICAL
📊
DI Speed Techniques
SPEED ▶
10% Base Method
Find 10% first, then build: 15% = 10% + 5%, 35% = 30% + 5%, 125% = 100% + 25%. Always start from 10%.
Percentage Share
% share = Part/Total × 100. In pie charts: each degree = 1/360 × 100 = 0.278%. Or: value = degree/360 × total.
% Change in DI
For approx: if change is small, use (Change/Original) × 100. Round to nearest 5% for elimination. Exact calculation only if options are close.
Ratio Comparison
Compare a/b vs c/d without cross-multiplication: if a/b > c/d then a×d > b×c. Saves time in DI comparisons.
Pie Chart Formula
Value of sector = (Degree/360) × Total % of sector = (Degree/360) × 100
1% = 3.6° · 10% = 36° · 25% = 90° · 50% = 180°
⚠️ DI Trap: % Change vs Percentage Point Change
Market share: 30% → 36%
Percentage POINT change = 36 - 30 = 6 percentage points
% change = (36-30)/30 × 100 = 20%
These are very different! CDS always tests this distinction.

Advanced Percentage Concepts

UPSC LEVEL
🔬
Percentage Points vs Percentages
ANALYTICAL ▶
Critical Distinction
If X changes from 30% to 45%: Percentage POINT change = 45 - 30 = 15 pp % CHANGE in percentage = (45-30)/30 × 100 = 50%
Always clarify: is the question asking % change or percentage point change?
⚠️ UPSC-CDS Confusion Zone
"Inflation rose by 2 percentage points" = from say 5% to 7%
"Inflation rose by 2%" = 5% × 1.02 = 5.1% (very different!)
In economics/statistics: percentage POINT = absolute change in % values
⚖️
Net Effect Analysis (Area, Volume)
GEOMETRY+% ▶
Rectangle Area Change
If L increases a%, W increases b% → Area change = a + b + ab/100 If L increases a%, W decreases b% → Area change = a - b - ab/100
⚡ Favorite CDS Area Questions
L+20%, W-20% → Area change = 20-20-4 = -4%
L+10%, W+10% → Area change = 10+10+1 = +21%
L+50%, W-50% → Area change = 50-50-25 = -25%
Cube side +10% → Volume change = 3(10) + 3(1) + 0.001 ≈ +33.1%
Cube Volume (side increases by r%)
Volume change% ≈ 3r + 3r²/100 + r³/10000
For small r, approximate as 3r%. For 10% → 33.1%

Option Elimination — Exam Hall Tactics
STRATEGY ▶
Units Check
If answer should be %, eliminate non-% options. If asking for a number, % answers are wrong.
Approximation Filter
Round numbers to nearest 5 or 10 first. If exact options differ widely, approximation eliminates 2-3 choices instantly.
Sign Check
After successive changes (one+, one-), result is LESS than lower of the two changes. Eliminates wrong-sign options.

% of something cannot exceed 100% unless explicitly stated. If answer >100%, it should be stated as "X times" not "X%".

CDS/UPSC Traps & Common Mistakes

AVOID ERRORS
⚠️
The 10 Deadliest Percentage Traps
CRITICAL ▶
🪤 Trap 1: Percentage Points ≠ Percentage Change
Savings rate: 8% → 10%. Change = 2 percentage points, but 25% increase in savings rate. Q will ask one, answer may reflect other.
🪤 Trap 2: Base Changes in Successive %
20% increase then 20% decrease ≠ 0. Net = -4%. Always use: a+b+ab/100 with signs.
🪤 Trap 3: Wrong Base for Profit% vs Discount%
Profit% base = CP. Discount% base = MP. Never mix these. A 20% discount on MP is very different from 20% profit on CP.
🪤 Trap 4: "X is Y% more than Z" Direction Matters
"A is 20% more than B" → A = 1.2B (B is base). "B is 20% less than A" → B = 0.8A → A = B/0.8 = 1.25B. DIFFERENT!
🪤 Trap 5: Population Increase Two Ways
10% per year for 2 years ≠ 20%. It's (1.1)² = 1.21 → 21%. Compound vs simple interest-style thinking applies here.
🪤 Trap 6: "What % is A of B" vs "What % is B of A"
A=30, B=120. A is 25% of B. B is 400% of A. Direction completely changes the answer!
🪤 Trap 7: Discount on Discount ≠ Sum of Discounts
20% + 10% discount ≠ 30%. Actual = 20+10-2 = 28%. Always apply successive discount formula.
🪤 Trap 8: Restoring After % Change
After 25% increase, to restore: need 20% decrease, NOT 25%! Formula: x/(100+x) × 100.
🪤 Trap 9: 100% vs 200% Increase
100% increase = doubles = ×2. 200% increase = triples = ×3. "Increased by 100%" ≠ "increased to 100%". "Increased to 100%" means it IS 100, not increased by 100.
🪤 Trap 10: Fraction Rounding in Conversion
1/3 = 33.33%, NOT 33%. 2/3 = 66.67%, NOT 67%. Rounding errors compound in multi-step problems. Keep fractions as fractions till the last step.

Formula Master Sheet

ONE-SHOT REVISION
📐 Core Definitions
x% = x/100 = 0.0x
% = (Part/Whole) × 100
Part = (% × Whole)/100
Whole = (Part × 100)/%
a% of b = b% of a (always!)
📈 Change Formulas
% Inc = (New-Old)/Old × 100
% Dec = (Old-New)/Old × 100
New = Old × (100±r)/100
Original = New×100/(100±r)
+r for increase, -r for decrease
⚡ Successive Changes
Net% = a + b + ab/100
3 changes: (1±a)(1±b)(1±c)-1
Restore after +r% = r/(100+r)×100
Restore after -r% = r/(100-r)×100
Sign of ab/100: same signs=+ve, diff=-ve
💰 Profit & Loss
P% = (SP-CP)/CP × 100
SP = CP(100+P%)/100
CP = SP×100/(100+P%)
Disc% = (MP-SP)/MP × 100
Profit base=CP · Discount base=MP
🏷️ Discount
SP = MP(100-D%)/100
2 disc: a+b-ab/100
MP = CP(100+P%)/(100-D%)
Net Profit = (1+m/100)(1-d/100)-1
m=markup%, d=discount%
🏘️ Population
P(n) = P₀(1+r/100)ⁿ
Decay: P₀(1-r/100)ⁿ
2yr net% = 2r + r²/100
Compound: same as CI formula
r=annual rate, n=years
📐 Area/Volume
Rect area: a+b+ab/100
Cube vol: ≈3r+3r²/100+r³/10⁶
Sphere: 3r% approx change
Circle area: 2r+r²/100
r = % change in side/radius
🎯 Ratio-% Bridge
a:b → a% = a/(a+b)×100
a:b:c → a% = a/(a+b+c)×100
Pie: sector = degree/360 × total
1° = 1/360 × 100 = 0.278%

UPSC-Level Aptitude Questions

ANALYTICAL
🏛️
10 UPSC CSAT Analytical Questions with Solutions
SOLUTIONS ▶
UPSC Q1 · 2 marks
In an election, candidate A gets 40% of total votes. B gets 60% more votes than C. The total votes are 7000. Votes obtained by B, if B got 36% of total votes, is:
Solution
B's votes = 36% of 7000 = 0.36 × 7000 = 2520 votes
Direct application. A=40%=2800, B=36%=2520, C=remaining=24%=1680. Check: B=60% more than C? 1680×1.6=2688 ≠ 2520. This means B got 36% is the given fact, not derived.
UPSC Q2 · Multi-step
A shopkeeper marks his goods 40% above cost price and allows a discount of 25%. Find his profit or loss percentage.
Solution — Multiplier Method
Let CP = 100. MP = 140. SP = 140 × 0.75 = 105. Profit = 5%
Net = (1 + 40/100)(1 - 25/100) - 1 = 1.4 × 0.75 - 1 = 1.05 - 1 = 0.05 = 5% profit
UPSC Q3 · Analytical
The population of a town increases by 10% in the first year and decreases by 10% in the second year. If the population after 2 years is 99,000, what was the original population?
Solution
Net change = 10 - 10 - 1 = -1%. So P × 0.99 = 99000. P = 99000/0.99 = 1,00,000
After +10% then -10%: multiplier = 1.1 × 0.9 = 0.99. So original = final/0.99.
UPSC Q4 · Income-Expenditure
A person spends 75% of his income. If his income increases by 20% and expenditure increases by 15%, find the % increase in savings.
Solution
Income=100, Exp=75, Savings=25. New Income=120, New Exp=75×1.15=86.25, New Savings=33.75. % increase = (33.75-25)/25 × 100 = 35%
Savings increase = ΔIncome - ΔExpenditure = 20 - (75×15/100) = 20 - 11.25 = 8.75. % change = 8.75/25 × 100 = 35%
UPSC Q5 · Three Successive Changes
A number is first increased by 10%, then by 10% again, and then decreased by 10%. What is the net percentage change?
Solution — Multiplier Chain
1.1 × 1.1 × 0.9 = 1.21 × 0.9 = 1.089. Net change = +8.9%
Always use multiplier chain for 3+ successive changes. Convert each to multiplier, multiply all, subtract 1.
UPSC Q6 · Mixture
Two vessels contain 60% and 40% acid solutions. In what ratio should they be mixed to get 52% acid solution?
Solution — Alligation
Ratio = (52-40):(60-52) = 12:8 = 3:2
Alligation rule: (Mean-Lower):(Higher-Mean). Mix 3 parts of 60% with 2 parts of 40% → check: (3×60+2×40)/5 = (180+80)/5 = 260/5 = 52% ✓
UPSC Q7 · Reverse Percentage
After successive discounts of 20% and 10%, the final price of an article is ₹720. Find the original marked price.
Solution
SP = MP × 0.8 × 0.9 = MP × 0.72. So MP = 720/0.72 = ₹1000
Work backwards: reverse each discount by dividing. 720 ÷ 0.9 = 800 (after 1st discount reversed), then 800 ÷ 0.8 = 1000.
UPSC Q8 · Area Change
If the length of a rectangle is increased by 20% and its breadth is decreased by 20%, what is the % change in area?
Solution
Net % = 20 + (-20) + (20×(-20))/100 = 0 - 4 = -4% (decrease)
Use formula a+b+ab/100 with a=+20, b=-20. ab/100 = -400/100 = -4.
UPSC Q9 · % Points Distinction
In 2022, party X won 45% votes. In 2023, it won 54% votes. By what percentage did its vote share INCREASE (not percentage points)?
Solution
% point change = 9 pp. But % CHANGE = (54-45)/45 × 100 = 9/45 × 100 = 20%
Question asks "percentage increase" which means % change in the percentage = 20%, NOT 9 percentage points. Read carefully!
UPSC Q10 · Complex Combined
A's salary is 20% more than B's, and B's salary is 25% less than C's. By what % is A's salary less than C's?
Solution — Chain Method
Let C = 100. B = 100 × 0.75 = 75. A = 75 × 1.2 = 90. A is less than C by 10%
Set C=100. B=C×(1-25/100)=75. A=B×(1+20/100)=90. A less than C = (100-90)/100×100 = 10%.
